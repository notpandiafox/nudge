# Building nudge from source

How to rebuild the Firefox add-on, the same files as the uploaded package,
from this source. Two parts of the add-on are generated by tools:

- `background.js`, `content.js` and `popup.js` are bundled by esbuild from
  the TypeScript in `extension/src/`. They aren't minified.
- `nudge.mjs` and `nudge.wasm` are the Wordle solver, compiled by Emscripten
  from the C++ in `solver/` (`solver/wasm/bindings.cpp` is the JavaScript
  interface). The word lists it uses are in `data/`.

`manifest.json`, `popup.html` and the icon (`assets/nudge_icon.svg`) are
copied as they are.

## What you need

- Node.js 24, with npm
- Emscripten 6.0.12 (`./emsdk install 6.0.12 && ./emsdk activate 6.0.12`)
- CMake 3.20 or newer, and Ninja

## Steps

From the top of the source:

```bash
emcmake cmake -S . -B build-wasm -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-wasm --target nudge_wasm
cd extension
npm ci
npm run build
```

`extension/dist/` is then the add-on, file for file the same as the uploaded
package. `npm run package` zips it into `extension/web-ext-artifacts/`.

The same steps run in CI on every push (`.github/workflows/ci.yml`, jobs
`wasm` and `extension`).
